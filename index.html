Project overview

The system starts from reconstructed 3D human motion and converts it into a structured comparison between a reference and learner performance. Instead of comparing videos frame by frame, the movement is segmented into phases, temporally aligned, and analysed through body-part-level errors. The XR viewer then presents the results spatially, allowing users to inspect where and when movement differences occur.

Complete framework pipeline

The demonstrator follows the complete thesis workflow: the original performances are processed into SMPL-X motion, normalized for comparison, segmented into movement phases, temporally aligned with DTW, converted into interpretable body-part errors, and finally presented through a browser-based WebXR scene.

01

Input performances

Reference and learner recordings are used as the source material. In this deployment, the exported dataset is loaded as data/experiment_01.json.

02

SMPL-X reconstruction

The PREMIERE processing pipeline provides reconstructed 3D body motion. Selected joints are extracted from the SMPL-X sequence for analysis.

03

Preprocessing

Motion is pelvis-centered, scale-normalized, and converted into joint trajectories suitable for phase detection, alignment, and error computation.

04

Motion flux and CPOP

Global motion flux summarizes changes in body movement. CPOP-style change-point detection divides the reference motion into data-driven phases.

05

Dynamic Time Warping

DTW aligns corresponding movement states between reference and learner sequences, even when the same action is performed with different timing.

06

Body-part metrics

Position, velocity, angle, and flux differences are computed for body regions such as head, torso, arms, and legs.

07

Analysis outputs

The pipeline exports JSON and CSV data containing phases, DTW mappings, frame metadata, metric curves, and phase-wise error summaries.

08

WebXR visualization

Three.js displays skeletons, heatmaps, ghost overlays, correction arrows, phase controls, and DTW panels in an interactive XR scene.
